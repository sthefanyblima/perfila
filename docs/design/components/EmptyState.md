# EmptyState

Ocupa o lugar de uma lista ou painel sem conteúdo, dizendo o que vai aparecer ali e como começar.

**O que fornecer.** `pf-empty` com título (o que falta), texto (o que vai aparecer e por quê) e a ação que cria o primeiro item. Com filtro ativo, a ação é "Limpar busca".

**Exemplos.** "Nenhum cliente cadastrado" + "Cadastrar cliente". "Este cliente ainda não foi processado" + "Processar agora". "Nenhum evento registrado" + "Registrar evento".

**Não faça.** Ilustração, emoji ou frase espirituosa.
